## 2026-09-24 — Scale fixes + on-device calibration tool
**What was done**: Grouper keeps member lists incrementally (groups() is O(groups), not O(library)); engine keeps id→item/sharpness maps incrementally and emits at most ~4×/s (was rebuilding whole-library dictionaries every 48 photos: quadratic on big libraries). Vision failures cached as an empty print (no retry every scan). 20k-photo scale test (whole suite 0.37 s). DEBUG-only Calibration screen + probe: histogram of feature distances for time-window pairs, reservoir-sampled pairs per 0.05 bin, sharpness percentiles; user labels "same moment"/"different" and "blurry"/"sharp" on-device; recommends the largest feature threshold with ≥ 90 % precision and the blur cut that best separates labels; applies via UserDefaults overrides (SimilarityConfig.current). Console prints numbers only. Release build compiles with the tool stripped. Signed + installed on iPhone 15 (iOS 27); App Group provisioned.
**Next steps**: User labels ~20 pairs + ~12 photos on device; read `[calibration]` lines from the devicectl console; bake the numbers into SimilarityConfig.standard and record in DECISIONS.md.
